
# E-Commerce Selenium Automation Framework

## About the Project

This project is an automated testing framework for an e-commerce web application using Selenium WebDriver and Java.

## Technologies Used

- Java
- Selenium WebDriver
- Maven
- TestNG
- Page Object Model
- Chrome WebDriver
- Git & GitHub

## Automation Scenarios

- Valid Login
- Invalid Login
- Product Selection
- Add Product to Cart
- Remove Product from Cart
- Cart Validation
- Checkout
- Order Confirmation
- Logout

## Framework Structure

src
├── main
│   └── java
│       ├── base
│       ├── pages
│       └── utilities
│
└── test
    └── java
        └── tests

## How to Run

Clone the repository:

git clone <your-github-repository-url>

Navigate to the project:

cd ECommerce-Selenium-Automation

Run tests:

mvn clean test
